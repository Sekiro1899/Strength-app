# Photos de fond

Dépose ici les 5 photos d'ambiance, puis décommente les `require()`
correspondants dans `lib/backdrops.ts`.

| Fichier attendu        | Photo                                    |
|------------------------|------------------------------------------|
| `01-wraps.jpg`         | Bandes de boxe, mains assises sur le tapis |
| `02-stack.jpg`         | Colonne de plaques d'une machine           |
| `03-airbike.jpg`       | Air bike sous les néons                    |
| `04-spin.jpg`          | Roues de vélos de biking                   |
| `05-rings.jpg`         | Anneaux de gym contre le mur               |

Format : JPEG, largeur 1200 px suffit — l'image est affichée en fond très
assombri, un fichier lourd ne se verrait pas et alourdirait le bundle.

Le passage en noir et blanc est appliqué à l'affichage, pas au fichier : tu
peux déposer les originaux en couleur.
